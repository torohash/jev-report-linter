# jev-report-linter

AIエージェントの報告からAI slopをなくすために、フックで動かすリンターを作るリポジトリです。

## 構想

Claude code および Pi Coding Agentのターミナル上で表示されるユーザーへの直接的報告について、AI slopな表現をJevを利用することで高速に分類し、適切な表現に修正する。

## Jev

わからなければ調べる

## 分類

修正、削除、正常、調査の4分類とする

修正はその文章の意味は必要だが、文法や表現に問題がある。

削除はその文章の存在自体の意図が不明瞭で、不要である場合。そのまま一文を削除する

正常は問題ないとしてそのまま報告の文書に加える。

調査は未確認や未確定といった表現が使われた場合とし、確定状態に持っていけるように調査させる。情報を調べてなお未決事項として保持しなければいけないものや、調べたうえで情報が存在しなかった。というケースの場合は正常扱いとする。
