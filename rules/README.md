# ルール

1ルール1ディレクトリで、`rules/<id>/rule.yml` に置く。

ルールの文は、出典の原文をそのまま引用する。言い換え、翻訳、条件の追加、例の追加はしない。引用が原文と一字一句同じであることは、`scripts/verify_quotes.py` で確かめる。

## 項目

| 項目 | 内容 |
|---|---|
| `category` | READMEの分類。削除、修正、調査 |
| `domain` | 出典が対象とする文書の種類。`common`（共通）、`tech`（技術記事）、`business`（業務文書）、`essay`（エッセイ）、`readme`（このリポジトリのREADME） |
| `detector` | `static` はコードで判定する。`jev` はJevに聞く |
| `subject` | 判定の単位。`sentence`（文）、`list-item`（箇条書きの1項目）、`heading`（見出し）、`document`（報告全体） |
| `match` | `static` では判定そのもの。`jev` では、Jevに聞く対象の絞り込み。`from` は、その正規表現や語の一覧をどこから取ったかを示す |
| `quote` | 出典の原文。`jev` のルールでは、これをそのままJevに渡す |
| `fix` | 直し方について書かれた出典の原文 |
| `note` | 出典に書かれておらず、このリポジトリで決めたこと |

## Jevへの聞き方

Jevには、報告の全文と対象の文を見せ、次の形で聞く。足す文は1行目だけで、2行目以降は `quote` の原文である。

```
次の記述に照らして、対象の文は該当する。

記述: （quote の原文）
```
