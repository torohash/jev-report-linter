# ルール

1ルール1ディレクトリで、`rules/<id>/rule.yml` に置く。

ルールの文は、出典の原文から抜き出す。言い換え、翻訳、条件の追加、例の追加はしない。抜き出した文が原文と一字一句同じであることは、`scripts/verify_quotes.py` で確かめる。

## 項目

| 項目 | 内容 |
|---|---|
| `category` | READMEの分類。削除、修正、調査 |
| `domain` | 出典が対象とする文書の種類。`common`（共通）、`tech`（技術記事）、`business`（業務文書）、`essay`（エッセイ）、`readme`（このリポジトリのREADME） |
| `detector` | `static` はコードで判定する。`jev` はJevに聞く |
| `subject` | 判定の単位。`sentence`（文）、`list-item`（箇条書きの1項目）、`heading`（見出し）、`paragraph`（段落）、`document`（報告全体）。出典の記述が述べている範囲に合わせる |
| `match` | `static` では判定そのもの。`jev` では、Jevに聞く対象の絞り込み。`from` は、その正規表現や語の一覧をどこから取ったかを示す |
| `applies` | 何に当たれば該当かを述べた、出典の原文の抜き出し。`jev` のルールだけが持つ |
| `excludes` | 何に当たれば該当しないかを述べた、出典の原文の抜き出し。出典に但し書きがあるルールだけが持つ |
| `basis` | ルールの根拠になった出典の文。直し方の指示を含む。判定には使わない |
| `note` | 出典に書かれておらず、このリポジトリで決めたこと |

## Jevへの聞き方

判定に使うのは `applies` と `excludes` だけである。「書き直す」「削る」といった直し方の指示は判定に渡さない。

Jevには、報告の全文と対象の文を見せ、次の形で聞く。足す文は各1行目だけで、記述は `applies` と `excludes` の原文である。

```
対象の文は、次の記述に当たる。
記述: （applies の原文）

次の記述に当たる場合は、該当しない。
記述: （excludes の原文）
```

`subject` が `paragraph` のルールは段落を、`document` のルールは報告全体を対象にして聞く。1行目の「対象の文」は「対象の段落」「対象の報告」になる。段落は、報告を空行で区切った塊のうち、文を2つ以上含むものである。

`applies` の原文をそのまま質問の文にする形は使わない。原文は「〜箇所」「〜場合」で終わるものが多く、言い切りの文にならないため、Jevの値が0.5付近に集まる（#6 で計測）。
